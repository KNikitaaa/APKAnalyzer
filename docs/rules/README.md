# Пакеты правил

Пакет правил обновляет **параметры** движка оценки риска без выпуска новой версии приложения:

| Поле | Что меняет |
|---|---|
| `weightOverrides` | вес отдельных правил (0–100), по ID из `RuleCatalog` |
| `disabledRules` | отключённые правила |
| `highThreshold`, `attentionThreshold` | пороги «Высокий риск» и «Нужно внимание» |
| `suspiciousTlds` | доменные зоны, популярные у злоумышленников |
| `dynamicDns` | сервисы динамического DNS и туннелей (подстроки) |
| `publicDns` | IP публичных DNS-резолверов (не считаются «зашитым сервером») |
| `messengerC2` | адреса мессенджеров, используемых как канал слива (подстроки) |

Логику правил пакет изменить не может — только числа и списки. Каждый пакет рассчитан на конкретную
версию встроенного каталога (`baseCatalog`), а в отчёт записывается версия вида `2026.10.2+2026.10.3`.

## Безопасность

- Приложение принимает **только подписанные** пакеты (ECDSA P-256, SHA-256). Открытые ключи —
  в `core/.../rules/pack/RulePackKeys.kt`.
- **Откат запрещён**: пакет старее самого нового когда-либо принятого не устанавливается, даже после
  «Вернуть встроенные правила». Так нельзя «подсунуть» старый пакет с ослабленными весами.
- Пакет проверяется при каждом запуске; если после обновления приложения он стал несовместим,
  действуют встроенные правила, а в настройках видно почему.
- **Закрытый ключ не хранится в репозитории.** Он лежит в соседней папке `../APKAnalyzer-keys/`.
  Если ключ утёк — создайте новый, добавьте его открытый ключ в `RulePackKeys`, удалите старый и выпустите
  версию приложения.

## Как выпустить пакет

```powershell
# 1. Описать пакет (см. пример rulepack-example.json): версия выше предыдущей, baseCatalog = текущий каталог.
# 2. Подписать (пакет проверяется тем же кодом, что и на телефоне):
.\gradlew.bat :core:signRulePack -Ppack=docs\rules\my-pack.json -Pkey=..\APKAnalyzer-keys\rulepack-signing.key -Pout=my-pack.rulepack
# 3. На телефоне: Настройки → «Правила оценки риска» → «Загрузить пакет правил».
```

Перед выпуском стоит прогнать замер качества с новыми параметрами (`docs/quality/EVALUATION.md`).

Новый ключ: `.\gradlew.bat :core:rulePackKeygen -Pkey=..\APKAnalyzer-keys\new.key`.

`rulepack-example.rulepack` — подписанный пример: добавляет зоны `.bond`, `.beauty`, `.hair`, `.quest`
и туннельные сервисы (`trycloudflare.com`, `loca.lt` и др.).
