# Образцы APK для ручной проверки

Сами файлы `*.apk` в git не попадают (см. `.gitignore`). Синтетические образцы создаёт `SampleApkGenerator` (тесты модуля `core`).

| Папка | Что там | Откуда |
|---|---|---|
| `synthetic/` | Синтетические APK: «подозрительный» (SMS + автозапуск + скрытая иконка + C2-адреса), «чистый», обрезанный, с испорченными данными, zip-bomb, «не APK», ZIP без манифеста | `SampleApkGenerator` в тестах модуля `core` |
| `real/` | Настоящие открытые приложения с F-Droid (заведомо безопасные) | скачиваются вручную с f-droid.org |

Синтетические APK **не являются вредоносными** — это просто структуры, на которых видно, как анализатор
реагирует на подозрительные признаки и повреждённые файлы. Установить их нельзя, только проанализировать.

Настоящие образцы вредоносного ПО сюда намеренно не загружаются. Если понадобятся для калибровки правил
(этап 2), их лучше брать из исследовательских наборов (например, MalwareBazaar, AndroZoo) и хранить
в изолированной среде, а не на рабочем компьютере.
